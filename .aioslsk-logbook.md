# Carnet de Bord — Projet Ordonnanceur

> **Changement de cap :** Le projet passe de "L'Armée des 12 Bots Soulseek"
> à un outil autonome d'organisation de fichiers audio : **l'Ordonnanceur**.
>
> L'utilisateur s'appelle désormais **Ordonnanceur**.

---

## 🎯 Mission

L'Ordonnanceur est un outil CLI + GUI qui analyse, organise, renomme,
dédoublonne et nettoie les fichiers audio téléchargés.

**Public :** Toute personne ayant des fichiers audio à organiser
(collectionneurs, DJs, utilisateurs de Soulseek, etc.)

**Philosophie :**
- Preview avant exécution (mode simulation par défaut)
- Opérations réversibles (dry-run/simulation)
- Résilient : chaque fichier est traité indépendamment
- Rapide : analyse de 10 000 fichiers en < 5 secondes

## 🏗️ Architecture

```
src/
├── cli_ordonnanceur.py          # CLI (argparse + preview console)
├── services/
│   └── ordonnanceur_service.py  # Backend complet (1652 lignes)
├── gui/
│   └── widgets/
│       └── bots/
│           └── bot_ordonnanceur.py  # GUI Qt (553 lignes)
└── models/
    └── schemas.py               # Modèles de données

tests/
├── test_ordonnanceur_service.py      # 128 tests backend
├── test_ordonnanceur_service_mutagen.py # Tests mutagen
└── test_cli_ordonnanceur.py          # 16 tests CLI

specs/
└── bot-ordonnanceur-spec.md     # Spécification détaillée
```

### Flux de données

```
AnalyseDossier → generer_apercu() → executer_operations()
                     ↓                    ↓
              Preview (CLI/GUI)    Disque (rename/move/delete)
```

### Dépendances

- `mutagen` — lecture tags audio (ID3, Vorbis, FLAC, etc.)
- `hashlib` — SHA256 pour dédoublonnage
- `pathlib` — manipulation chemins
- `argparse` — CLI
- `PySide6` — GUI (Qt)
