## 🔧 Architecture retenue

Chaque bot = une classe dans `src/gui/widgets/bots/`, héritant de `QFrame` :

```
src/gui/widgets/bots/
├── __init__.py
├── bot_accueil.py            # ✅ 652 lignes
├── bot_accueil_knowledge.py  # ✅ Dictionnaire 18 entrées
├── bot_wishlist.py            # ✅ 719 lignes + WishlistCard
├── bot_recherche.py           # ✅ En cours — ~1979 lignes → QTableWidget 9 colonnes, tri bitrate ↓, filtre audio toggle, modal filtres avancés, bouton Stop + annulation réseau, mode dispo 🟢, menu contextuel (clic droit), mode Browse User 👤, mode Salon 💬 #, FIFO 200, historique JSON 📜 (suggestions, popup, effacer, suppr. indiv.)
├── bot_surveillance.py        # 🔄 À créer (spec prête)
├── bot_telechargement.py      # ❌
├── ...
```

### Services

```
src/services/
├── __init__.py
├── soulseek_client.py         # ConnexionManager + SoulseekService
├── app_config.py              # Configuration fonctionnelle (get/set/reset)
├── search_history.py          # ✅ 159 lignes → SearchHistory : persistance JSON, 20 entrées max, dédoublonnage, CRUD complet
├── event_bus.py               # 🔄 À créer — bus d'événements central + SQLite
```

### Données persistantes

```
data/
├── description.json           # Fichier de description (usage générique)
├── bot_recherche_history.json # Géré par SearchHistory
├── bot_surveillance.db        # 🔄 À créer — SQLite des événements surveillés
```

Navigation : Footer (boutons) → `page_changed(nom)` → `CenterZone.show_page(nom)`

Backend : `ConnexionManager` dans `soulseek_client.py`
- Signaux : `connected`, `disconnected`, `error_occurred`, `search_result_received`, `status_changed`
- API publique : `login()`, `generate_account()`, `disconnect()`, `search()`, `stop_search()`, `shutdown()`
