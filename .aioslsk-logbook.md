**Date:** Terminée

**Demande:** Créer la structure du projet Python et l'interface FastAPI de connexion
**Résultat:** ✅ Projet créé et prêt à tester

**Fichiers créés:**
- `requirements.txt` — Dépendances Python (aioslsk, fastapi, uvicorn, pydantic)
- `src/__init__.py` — Package principal
- `src/main.py` — Point d'entrée FastAPI avec CORS, shutdown hook
- `src/config.py` — Configuration via pydantic-settings (préfixe `AISLSK_`)
- `src/models/schemas.py` — Schémas ConnectRequest, ConnectResponse, StatusResponse
- `src/services/soulseek_client.py` — Service wrapper SoulSeekClient (start → login → stop)
- `src/routers/connection.py` — Endpoints POST /api/connect, POST /api/disconnect, GET /api/status

**Endpoints FastAPI créés:**
| Méthode | Route | Description |
|---------|-------|-------------|
| GET | `/` | Health check racine |
| POST | `/api/connect` | Connexion à Soulseek (username + password) |
| POST | `/api/disconnect` | Déconnexion |
| GET | `/api/status` | Statut de la connexion |

**Tests utilisateur:** ⏳ En attente
**Notes:**
- Architecture propre : models séparés des routers et services
- Le service utilise un singleton global pour le client
- Cycle de vie: `start()` → `login()` → `stop()` (basé sur la doc officielle)
- Le shutdown de FastAPI déconnecte automatiquement
