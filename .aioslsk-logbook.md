## Architecture

Chaque option suit le même pattern :

1. **app_config.py** — Défaut + clé de configuration persistée (fichier JSON)
2. **center.py** — Widget UI (ConfigToggle/ConfigSpin/ConfigEntry/ConfigCombo/ConfigFilePicker/ConfigDirectoryPicker) ajouté à la bonne page
3. **soulseek_client.py** — Lecture de la config au démarrage + passage au constructeur `Settings()`
4. **left.py** — Bouton de navigation dans `_SECTIONS`

*Règle : jamais d'option UI sans backend câblé.*
