## 🔧 Architecture retenue

Chaque bot = une classe dans `src/gui/widgets/bots/`, héritant de `QFrame` :

```
src/gui/widgets/bots/
├── __init__.py
├── bot_accueil.py
├── bot_recherche.py
├── bot_telechargement.py
├── bot_wishlist.py
├── ...
```

Navigation : Footer (boutons) → `page_changed(nom)` → `CenterZone.show_page(nom)`

Backend : `ConnexionManager` dans `soulseek_client.py`
