## Bot Bibliothèque

Le **bot Bibliothèque** est le gestionnaire de fichiers partagés. Il permet d'explorer, filtrer et gérer ta bibliothèque locale partagée sur le réseau Soulseek.

### Interface

- **Tableau de bord** : vue d'ensemble de ta bibliothèque (nombre de fichiers, taille totale)
- **Liste des fichiers** : exploration complète avec colonnes triables
- **Filtres** : filtre par type de fichier, dossier, extension
- **Statistiques** : volume total, répartition par type, dossiers

### Fonctionnalités

| Fonction | Description |
|----------|-------------|
| **Exploration** | Parcours tous les fichiers partagés avec navigation par dossier |
| **Filtrage** | Filtre par type audio, video, image, document, etc. |
| **Recherche** | Cherche un fichier spécifique dans ta bibliothèque |
| **Stats en direct** | Nombre de fichiers, taille totale, répartition |
| **Connexion** | Si déconnecté, bouton rapide pour aller à la page de connexion |

### Partage

Ta bibliothèque est automatiquement partagée sur le réseau Soulseek quand tu es connecté. Les autres utilisateurs peuvent :

- Parcourir tes fichiers (browse)
- Télécharger tes fichiers partagés
- Voir les statistiques de ta collection

### Astuces

- Organise tes fichiers par dossiers avant de les partager
- Les formats audio (mp3, flac) sont prioritaires dans l'affichage
- Vérifie régulièrement que tes dossiers partagés sont accessibles
