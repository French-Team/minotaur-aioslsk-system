## Bot Wishlist

Le **bot Wishlist** permet de configurer des souhaits de recherche automatiques. Ajoute un mot-clé, et l'application surveille le réseau pour toi. Quand un fichier correspondant est trouvé, tu reçois une alerte.

### Interface

- **Tableau de bord** : vue d'ensemble de tous tes souhaits actifs
- **Cartes de souhait** : chaque souhait affiche son état, sa fréquence, et ses résultats
- **Bouton Ajouter** : créer un nouveau souhait en quelques clics

### Fonctionnalités

| Fonction | Description |
|----------|-------------|
| **Ajout de souhait** | Entre un mot-clé (ex: "album jazz 2024") |
| **Fréquence** | Configure la fréquence de recherche (quotidienne, hebdomadaire, etc.) |
| **Notifications** | Reçois des alertes quand un résultat correspond à ton souhait |
| **Modification** | Modifie ou supprime un souhait existant |
| **Statut en direct** | Voir si le souhait est actif, en pause, ou terminé |

### Intégration

- **Planificateur** : les souhaits peuvent être exécutés via des actions planifiées
- **Surveillance** : les résultats apparaissent dans le flux d'événements
- **Téléchargement** : les fichiers trouvés peuvent être téléchargés automatiquement

### Astuces

- Plus le mot-clé est précis, meilleurs sont les résultats
- Combinaison avec le Planificateur = recherche automatique programmée
- Active les badges dans le footer pour voir le compteur de souhaits
