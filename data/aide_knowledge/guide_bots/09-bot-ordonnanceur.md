## Bot Ordonnanceur

Le **bot Ordonnanceur** est l'assistant d'organisation des téléchargements. Il t'aide à classer, renommer, dédoublonner et nettoyer les fichiers téléchargés en un assistant pas à pas.

### Interface

L'Ordonnanceur fonctionne en **4 étapes** :

| Étape | Action |
|-------|--------|
| **1 — Sélection** | Choisis les fichiers ou dossiers à organiser |
| **2 — Règles** | Configure les règles de classement (par artiste, album, genre, etc.) |
| **3 — Aperçu** | Visualise le résultat avant application |
| **4 — Application** | Lance le traitement effectif |

### Règles de classement

- **Par artiste** : crée un dossier par artiste
- **Par album** : crée un dossier par album
- **Par genre** : classe par genre musical
- **Par année** : classe par année de sortie
- **Personnalisé** : définis tes propres règles

### Fonctionnalités

- **Renommage automatique** : nettoie les noms de fichiers (numéros de piste, underscores)
- **Dédoublonnage** : détecte et supprime les fichiers en double (par hash ou par nom)
- **Nettoyage** : supprime les fichiers indésirables (.nfo, .txt, .jpg)
- **Aperçu avant validation** : vérifie le résultat avant d'appliquer
- **Annulation** : possibilité d'annuler le traitement après application

### Astuces

- Utilise l'aperçu (étape 3) pour vérifier avant d'appliquer
- Configure des règles par défaut dans l'Optimiseur
- Lance l'Ordonnanceur après une session de téléchargement intensive
