## Bot Téléchargement

Le **bot Téléchargement** gère l'ensemble des transferts (downloads et uploads) sur le réseau Soulseek. Il affiche la progression en temps réel, les statistiques, et permet de contrôler chaque transfert.

### Interface

- **Tableau des transferts** : liste complète des fichiers en cours d'échange
- **Barre de progression globale** : visualisation du volume total transféré
- **Toolbar** : actions rapides (pause, reprise, annulation)
- **Navigation inter-bots** : lien direct vers le bot Recherche pour trouver d'autres sources

### Fonctionnalités

| Fonction | Description |
|----------|-------------|
| **File d'attente** | Les téléchargements s'organisent automatiquement par priorité |
| **Choix du meilleur pair** | Sélection automatique de la meilleure source (slots libres + meilleure vitesse) |
| **Statistiques** | Vitesse moyenne, volume total, ratio download/upload |
| **Barre de progression** | Suivi visuel en temps réel de tous les transferts actifs |
| **Uploads** | Visualisation des fichiers que vous partagez avec d'autres utilisateurs |

### Actions disponibles

- Mettre en pause / Reprendre un transfert
- Annuler un téléchargement
- Changer la priorité d'un fichier
- Ouvrir le dossier contenant le fichier téléchargé
- Copier le nom du fichier

### Astuces

- Utilise le mode **disponible** dans le bot Recherche pour trouver des sources avec slots libres
- Vérifie les limites de vitesse dans l'Optimiseur si les téléchargements sont lents
- Le bot Planificateur peut déclencher des téléchargements automatiques
