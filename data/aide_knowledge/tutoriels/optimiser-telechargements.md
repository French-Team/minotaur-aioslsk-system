## Optimiser les téléchargements

Ce tutoriel explique comment améliorer la vitesse et la fiabilité de tes téléchargements.

### Étape 1 : Vérifier ta connexion

1. Va dans **Optimiseur** → profil **Performance**
2. L'optimiseur ajuste automatiquement :
   - Le nombre de connexions simultanées
   - La bande passante maximale
   - Les timeouts réseau
3. Attends la fin de l'application du profil

### Étape 2 : Configurer les limites

Si le profil Performance ne suffit pas, ajuste manuellement :

1. Va dans **Configuration** → section **Téléchargement**
2. Paramètres recommandés :

| Paramètre | Valeur conseillée |
|-----------|-------------------|
| **Limite de vitesse** | 0 (illimité) ou selon ta connexion |
| **Slots max** | 10-20 |
| **Connexions max** | 100-200 |

### Étape 3 : Utiliser le mode disponible

1. Va dans **Recherche**
2. Active le toggle 🟢 **Mode dispo** (slots libres seulement)
3. Seuls les utilisateurs avec des slots libres apparaissent
4. Résultat : téléchargement immédiat, pas d'attente

### Étape 4 : Prioriser les bonnes sources

Quand tu cherches un fichier :

1. Regarde la colonne **Slots** : privilégie les utilisateurs avec slots libres
2. Regarde la colonne **Vitesse** : favorise les vitesses élevées
3. Regarde la colonne **DL** : plus il y a de sources, mieux c'est
4. Clic droit sur un résultat → **Téléchargement rapide** vers le meilleur pair

### Étape 5 : Surveiller les performances

1. Va dans **Téléchargement**
2. Observe la barre de progression globale
3. Vérifie les statistiques (vitesse moyenne, volume total)
4. Si un téléchargement est trop lent, cherche le fichier chez un autre utilisateur

### Astuces avancées

- **Horaire** : télécharge aux heures creuses (nuit, matin) pour moins de concurrence
- **Multi-sources** : le même fichier peut être téléchargé depuis plusieurs utilisateurs
- **Liste noire** : bloque les utilisateurs trop lents via le menu contextuel
