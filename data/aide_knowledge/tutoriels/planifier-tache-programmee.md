## Planifier une tâche programmée

Ce tutoriel explique comment créer une action planifiée qui s'exécute automatiquement à une heure définie.

### Étape 1 : Aller dans le Planificateur

1. Clique sur **Planificateur** dans le footer
2. Tu vois le tableau de bord avec la liste des actions existantes

### Étape 2 : Créer une nouvelle action

1. Clique sur **Nouvelle action** dans la barre d'outils
2. Une fenêtre modale s'ouvre

### Étape 3 : Configurer l'action

1. **Type** : choisis le type d'action (Recherche Wishlist, Nettoyage, etc.)
2. **Nom** : donne un nom explicite à l'action
3. **Description** : décris ce que fait l'action (optionnel)

### Étape 4 : Définir l'horaire

1. **Mode** : choisis "Planifié"
2. **Date** : sélectionne la date d'exécution
3. **Heure** : choisis l'heure exacte
4. **Récurrence** : si nécessaire, active la répétition (quotidienne, hebdomadaire, mensuelle)

### Étape 5 : Sauvegarder

1. Vérifie les paramètres dans le récapitulatif
2. Clique sur **Sauvegarder**
3. L'action apparaît dans la liste avec le statut "Actif"

### Vérification

- L'action doit avoir le statut ✅ **Actif**
- Tu peux la mettre en pause ⏸️ si nécessaire
- Le badge du Planificateur dans le footer indique le nombre d'actions actives

### Exemple concret

```
Nom : "Recherche jazz du matin"
Type : Recherche Wishlist
Déclencheur : Planifié
Horaire : Tous les jours à 08:00
Récurrence : Quotidienne
```

Cette action lance une recherche automatique des mots-clés de ta Wishlist tous les matins à 8h.
