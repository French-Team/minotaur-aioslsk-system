## Comment utiliser les badges du footer

Les **badges** sont des indicateurs numériques qui apparaissent sur les boutons des bots dans le footer. Ils te donnent un aperçu rapide de l'activité sans changer de page.

### Où voir les badges ?

Chaque bot peut afficher un badge sur son bouton dans le footer :

| Bot | Badge indique |
|-----|---------------|
| **Surveillance** | Nombre d'événements non lus |
| **Téléchargement** | Nombre de transferts en cours |
| **Planificateur** | Nombre d'actions en attente |
| **Clients Actifs** | Nombre de clients connectés |

### Comment ça marche ?

- Les badges se mettent à jour automatiquement en temps réel
- Ils sont visibles depuis n'importe quelle page de l'application
- Le badge disparaît quand tu vas sur la page concernée
- Les couleurs peuvent varier selon l'urgence (vert INFO, orange WARN, rouge ERROR)

### Astuces

- Jette un œil aux badges régulièrement pour ne rien manquer
- Un badge rouge sur Surveillance signifie une erreur à vérifier
- Clique sur le bouton avec le badge pour voir les détails
